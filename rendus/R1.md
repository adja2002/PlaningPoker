## 3. Definition of Done et objectif du sprint 1

Une US est **terminée** quand **toutes** les conditions suivantes sont vraies (DoD proposée : adoptez-la ou modifiez-en une).

| # | Condition | Comment on la vérifie |
|---|---|---|
| 1 | Les critères d'acceptation de l'US sont satisfaits | Un test par critère, nommé avec son identifiant (à partir de la séance 2) ; sinon essai à la main |
| 2 | Le code a été relu par le copilote | La PR porte un commentaire ou une approbation du copilote |
| 3 | Les tests passent | La commande de test du README réussit ; la CI est verte (à partir de la séance 2) |
| 4 | Le README est à jour si la façon de lancer ou de tester a changé | Les commandes du README fonctionnent après un `git clone` |
| 5 | Si l'IA a servi, une entrée existe dans `AI_LOG.md` | L'entrée cite l'US |

Modification éventuelle (laquelle, pourquoi) : aucune, DoD adoptée telle quelle.

**Objectif du sprint 1** (une phrase, orientée utilisateur) : l'animateur peut lancer une partie en saisissant les joueurs et leurs pseudos,puis charger un backlog et voir la première fonctionnalité estimer.
